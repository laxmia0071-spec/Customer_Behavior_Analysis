## 8. How to Run

### Prerequisites
- Python 3.x
- Jupyter Notebook or VS Code
- PostgreSQL, MySQL, or SQL Server
- Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone <your-repository-url>
cd data-analytics-project
```

### Step 2: Install Dependencies

```bash
pip install -r requirements.txt
```

Example `requirements.txt`:

```text
pandas
numpy
matplotlib
seaborn
jupyter
sqlalchemy
```

Install a database-specific driver if required for your chosen database.

### Step 3: Run the Python Analysis

Open Jupyter Notebook:

```bash
jupyter notebook
```

Open `notebooks/data_analysis.ipynb` and execute the cells in order.

### Step 4: Execute SQL Queries

- Start your chosen database server.
- Create a database and import the prepared dataset.
- Open `sql/analysis_queries.sql` in your database client.
- Execute the queries to reproduce the analysis.

Update database connection settings according to your local environment.

### Step 5: Open the Power BI Dashboard

Open `dashboard/dashboard.pbix` in Power BI Desktop.

Configure the data source if prompted, refresh the data, and explore the dashboard.

### Step 6: View the Report and Presentation

Open the project report in the `reports/` folder and the presentation in the `presentation/` folder.
